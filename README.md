# 合作收益分析（本地应用）

一个从零构建、纯本地运行的合作博弈收益分析工具。录入虚构参与方、联盟可实现收益与
共享成本后，应用计算 Shapley 贡献分配、检查核心稳定性（哪些联盟有退出动机），并在
最低保障与总额约束下求与原贡献最接近的可行方案。

**仅用于虚构示例与教学分析，不涉及任何真实结算。** 无第三方依赖：后端仅用 Python
标准库，前端为原生 HTML/CSS/JS，无需构建步骤。

## 快速开始

需要 Python 3.9+，无需安装任何包。

```bash
# 在仓库根目录启动（默认 127.0.0.1:8000，数据存于 data/store.json）
python3 -m backend.server

# 常用选项
python3 -m backend.server --host 127.0.0.1 --port 8022 --data data/mygame.json
```

启动后浏览器打开 `http://127.0.0.1:<端口>/` 即可。数据以 JSON 原子写入本机文件，
不向任何外部服务发送请求。

## 功能与设计要点

### 1. Shapley 贡献：精确与抽样两条路径

- **小规模（n ≤ 12）精确枚举**全部 n! 排列对应的边际贡献。
- **大规模排列抽样**：确定性 SplitMix64 随机流，批均值法给出 Student-t 95% 置信
  半宽。任务状态持久化 RNG 游标，**恢复时从断点续算，排列不重复累计**；游戏内容
  指纹不匹配时拒绝续算，防止换了游戏却沿用旧游标。
- 效率公理被独立核对：Σ Shapley 与大联盟净值之差必须为 0（界面"独立核对"区展示）。

### 2. 缺失联盟价值绝不默认成零

未录入的联盟价值是"未知"而不是 0。可对联盟录入下界/上界（两侧留空表示完全
无界），严格的边际区间 `[w_lo(S∪i) − w_hi(S), w_hi(S∪i) − w_lo(S)]` 传播为每个
参与方的 Shapley 值区间。无界联盟在稳定性报告中单独列出，不会被静默丢弃。

### 3. 核心稳定性与空核证据

- 小博弈枚举全部联盟约束，一次 LP 求出真实最小核 ε*：ε* ≤ 0 核心非空（负值为
  松弛量），ε* > 0 核心为空。
- **核心为空时绝不声称"已经公平"**：给出 ε=0 不可行的 LP 证据、最小统一补偿
  ε*（最小违约方案）以及同时绑定的联盟列表；界面按退出动机差额对联盟排序。
- 大博弈采用约束生成（割平面），只把被违反的联盟加入 LP，并明确标注结论仅覆盖
  已录入联盟。区间博弈分别按下界/中点/上界三个情景求解，给出 ε* 区间而非单一
  断言。

### 4. 保障 + 总额约束下的最近可行方案

给定每个参与方的最低保障（可锁定）与总额预算，求欧氏距离上最接近原 Shapley
贡献的可行分配：KKT 水位线（water-filling）闭式投影，二分法求拉格朗日乘子。
当保障之和本身超过预算、无可行解时，返回最小违约方案（统一折扣 δ）与各方缺口，
而不是报错了事。区间博弈额外输出低/高目标情景下的方案范围。

### 5. 版本与审计

- 每次提交生成不可变 JSON 快照（语义指纹，与录入顺序无关），新版本激活时旧版本
  自动转为只读，历史方案原样保留。
- 网页支持：编辑任意联盟的价值/界/成本、锁定保障金额、查看最不稳定联盟及其差额、
  深色模式、图表悬停提示；状态色均带图标与文字标签，不依赖颜色单独传达信息。

```

  server.py         # http.server 路由 + 静态文件服务
frontend/           # 原生单页应用（index.html / styles.css / app.js）
tests/run_tests.py  # 27 个独立核对测试
```

## 理论备注

按人头均分与"逐个去掉"的边际贡献在一般博弈中并不等价：只有 Shapley 值同时满足
效率、对称、虚设与可加四条公理，且它是所有排列边际贡献的期望。本工具把均分留给
用户自行对比，默认分配始终基于边际贡献；核心是否为空则由 LP 独立判定，与
Shapley 值是否落在核内是两个不同的问题。
